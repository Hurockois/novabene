# Novabene

Le journal du matin et du soir de Hugo, en application web (PWA).

- `index.html` : dernière édition du matin
- `soir.html` : dernière édition du soir
- `archives/` : éditions passées
- `build.py` : `python3 build.py matin|soir edition.html` assemble une édition publiée dans Claude en page d'application et l'archive

Publié avec GitHub Pages (branche `main`, dossier racine).
